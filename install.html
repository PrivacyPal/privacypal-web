Step by step · Windows

Installing on Windows 11

01

Download the installer

Grab PrivacyPal-Setup-1.8.10.exe above — or skip the browser entirely and run winget install PrivacyPal.AI from PowerShell.

02

Run the setup

Run the installer as a user with permission to install applications. SmartScreen may ask you to confirm the publisher — accept to continue.

03

You're protected

PrivacyPal installs silently and begins protecting the moment it's active — every AI app on the machine, zero configuration required.

Step by step · macOS
Installing on macOS

Drag, open, approve

Three quick steps from .dmg to full coverage on any Mac — Apple Silicon or Intel.

01 — Drag to Applications

Open the .dmg and drag PrivacyPal to your Applications folder.

02 — Pass Gatekeeper

On first launch Gatekeeper may block the app — right-click PrivacyPal in Applications and choose Open, then confirm.

03 — Grant permissions

Approve any privacy or accessibility permissions PrivacyPal requests — that's what lets it govern AI at the system edge.
