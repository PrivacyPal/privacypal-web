# Brand sources

- `twemoji-1f427.svg`: the penguin emoji (U+1F427) from Twemoji v17.0.3
  (https://github.com/jdecked/twemoji), Copyright Twitter, Inc. and other contributors, licensed under
  CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Used unaltered as the PrivacyPal logo mark.
- `penguin.svg`, `penguin-flat.svg`, `penguin-dark.svg`: the same emoji placed on a 512 canvas
  (no change to the drawing).
- `wordmark.svg`: "PrivacyPal" outlined from Overused Grotesk 600 (OFL) by `scripts/brand/outline-wordmark.py`.

Build every output with `npm run brand` (Node 20). Attribution for the penguin is shown in the site footer
and on the brand guide page, as CC BY 4.0 requires.
