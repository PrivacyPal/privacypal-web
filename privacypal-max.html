Privacy Agents

Policies that reason about privacy, intent and risk

Privacy Agents are governance policies enforced on the device that reason about privacy, intent and risk in real time: out of the box, custom-built, or from the marketplace. Block models, gate access behind training paths, intercept and steer prompts, redact at the wire.

Detection & authorization

Agent and prompt intent detection

Understand what an agent is trying to do before it does it. Authorize, alert or quietly redact based on intent, not just keywords.

Adversarial defense

Prompt Injection Guard

Catch jailbreaks, tool-call hijacks and exfiltration patterns at the endpoint. The policy reasons about adversarial intent so your people can keep working.

Vertical enrichment

Legal, Financial and domain agents

Drop in a Legal Agent that knows privilege, or a Financial Agent that knows MNPI. Agents bring vertical intelligence to every interaction, with no model to retrain.

Day in the life

Governance, lived from the device out

01

A developer starts a Claude Code session on customer code

Agent governance recognizes the repo, the on-device DSPM knows the secrets and PII inside it, and Privacy Twins substitute customer identifiers before any prompt or tool call leaves the laptop. Claude Code keeps moving, and your IP never reaches the AI provider.

02

A sales engineer pastes a customer architecture into ChatGPT

Intent Detection recognizes the workflow, the Legal Agent flags an NDA clause, and Privacy Twins swap vendor names, all before the request leaves the device. The CISO sees the event in the activity feed. Nobody loses time.

03

Microsoft Copilot is asked to summarize a finance folder

On-device DSPM has already classified the data as MNPI. Org-wide controls require Copilot users to be in the client-facing training cohort. Enrolled users get their summary with Privacy Twins in place of the names; everyone else is redirected at the endpoint.

04

Finance wires up a Private MCP for the general ledger

Engineers, analysts and a custom Financial Agent all share the same internal context over MCP, under one policy, kept off any public host. Same fluency. Full audit.
